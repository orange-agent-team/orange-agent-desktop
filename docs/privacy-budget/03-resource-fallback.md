# 本地资源不足状态稿

PRD-004.03 的入口是用户选择 LocalOnly 后，遇到缺少模型文件、容量不足、模型校验失败或启动失败。状态页保留工作区选择，显示未就绪的原因。进入此页不会提交远程 Job。

| 可见选择 | 前提 | 用户动作后的状态 |
|---|---|---|
| 下载模型或导入已有文件 | 模型在当前受支持的清单内，文件大小和本地存储可核对 | 为固定模型另行确认传输；下载完成核验摘要后才显示可启动。取消会留下本地状态供核对 |
| 换模型 | 清单中存在其他可选配置，原实例已停止，旧调用的效果已经核对 | 选中新版本后重新显示需求和身份。只有一项经核验时显示此限制及继续留在本地的办法 |
| 允许远程处理 | 用户显式离开 LocalOnly，已选择有权使用的个人或团队预算 | 显示源范围、平台与目标节点、明文风险和输入预览；独立批准上传并取得报价，再确认作业。缺少身份、报价或授权时停在对应步骤 |
| 退出或稍后处理 | 任意缺资源状态 | 关闭选择，保留本地文件和授权记录。下次继续时重新检查模型、权限和预算 |

当 CPU 模型被中断，界面应显示“核对原会话”，区分已发生的文件效果、未确认的模型派发及尚未提交的提案。切换设备或模型不能把旧请求自动重放。

当前桌面开发包支持固定模型的导入、下载、校验和取消。远程文本与转写的完整授权、报价及提交已在用户 Web 验收。桌面内直接远程下单仍有单独实施项。7B 桌面候选的选择界面与整个模型作业资格分别验收。
