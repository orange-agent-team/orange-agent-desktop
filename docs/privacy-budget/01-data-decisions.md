# 发送前的数据决策

PRD-004.01 对应个人或团队计算任务、离线桌面会话和托管 Agent。文本处理方式默认为留在本地。发送范围变大、接收节点变化或预览中的字节变化后，客户端须重新取得确认。

| 用户的动作 | 离开设备的数据与接收者 | 确认前应显示的内容 | 本次费用上限 |
|---|---|---|---|
| 桌面本地会话 | 工作区文件、会话文本和工具结果由本机宿主处理。文件读取和修改分别取得授权 | “在本机运行。读取具体文件时会列出路径，修改还需核对差异。” | 平台算力费用 0；使用本机资源 |
| 下载模型 | 模型来源收到文件下载请求；模型文件进入本机私有缓存。用户文档和提示词留在工作区 | 文件名、来源、大小及本地核验方式。确认下载后才开始传输 | 平台算力费用 0 |
| Web 仅在浏览器编辑 | 文本草稿保留在本页，模型选择和预算列表可单独从平台读取 | “当前文本保留在本页。”离开页面前用户自行保存需要的草稿 | 0 |
| Web 发送原文询价 | 平台收到用户核对的 UTF-8 请求，包括任务文本、调用编号、模型及输出上限 | 展示完整预览、字节数、SHA-256、所属预算和选定的节点。批准上传后才开始计量 | 0；冻结操作另行确认 |
| Web 发送规则遮盖文本询价 | 平台只收到预览里的替换结果。规则按精确原字符匹配，重叠时先匹配较长片段 | 展示“已遮盖”的实际位置和替换次数。提醒用户核对同义词、文件名、上下文等残余线索 | 0 |
| 提交远程文本任务 | 已审核的执行节点取得本次批准的文本，可以读取明文。平台接收结果和计量回执 | 原报价、节点、模型版本、最大预留、付款归属和本人可见的可用额度 | 服务端原报价的 max_amount |
| 音频上传预检 | 平台收到选定文件的原始音频并测量时长 | 文件、大小、个人或团队空间；文字遮盖规则不改变音频 | 0 |
| 同意远程转写与提交 | 授权绑定原音频版本、节点观测、模型、地区、调用和预算。节点在有效租约中读取原音频 | 分别确认“允许此节点读取当前音频”及“确认预留并提交转写” | 授权为 0；作业为原转写报价上限 |
| 托管 Agent 续段 | 当前模型步骤可使用原输入及已批准的工具结果 | 显示此次步骤使用的来源、原根预算、模型和新报价。高风险工具沿用各自审批 | 此步骤的原报价上限 |

**遮盖后的明文仍可能识别个人。** 例如去掉邮箱后，职位和会议日期仍可能暴露身份。规则匹配不能提供匿名性或节点内的保密计算保证。修改源文本、规则、模型、预算或输出上限会使旧预览失效。浏览器恢复记录只需不可变编号、摘要和状态，重开会话不能从这些字段取得新的上传或消费批准。

本地策略、报价显示及故障回退分别由桌面宿主、用户 Web 和服务端的预算/授权接口执行。此表是产品文案与策略合同；具体目标平台和真实模型的资格以相应发行验收为准。
