# 桌面本地运行模板

在“本地会话”中选择已授权工作区和本地模型。“运行模板”默认为通用会话。目录来自原生宿主的固定共享 Runtime，包含文本摘要和授权文件问答。选择模板后可以查看指令、工具、版本及摘要，再为当前本地所有者启用。启用操作只保存模板选择，模型推理仍由“开始会话”发起。

摘要只接收任务文本。问答可以申请 read_file 和 search_text，每次文件操作仍经过工作区授权、运行日志与原生批准。选择模板时会收起通用会话的写入、记忆和提问选项。若目录暂时不可读或原选版本消失，开始入口保持关闭，用户可重新读取目录或明确选择通用会话。

回答下的“已核对的来源”来自宿主已提交的工具回执，包括相对路径、字节范围和 SHA-256。Flutter 只显示本次授权视图返回的引用。若源文件改变、目录访问被撤销或会话内容隐藏，原引用需要重新核验。模型正文里提到的其他文件不会自动成为已核对来源。

设置状态和启动均通过本地 Rust 桥接，模型不能调用模板管理方法。私有工作区内容继续沿用宿主的 SQLite 和文件授权边界。[固定共享源码版本](../config/runtime.lock.json)

开始请求同时携带选定版本的激活修订。宿主在打开 Run 前再次读取该所有者的激活状态，即使停用后又启用了相同摘要，先前修订的延迟请求也会被拒绝。启动模板的接口只接收工作区、任务文本和原选择，不接收额外的写入或记忆授权。
