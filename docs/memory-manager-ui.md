# 本地记忆管理界面候选

MemoryPanel已接入默认LocalAgentShell，通过生成的FRB Memory API管理真实SQLite记录。支持空间创建、明确只读/编辑访问、来源工作区/记忆授权、条目分页、完整读取、保存/删除预览与确认、停用条目/空间、成员权限和无正文请求回执查询。

控制器在关闭、切换空间和原始工作区访问失效时提升请求代次并清空正文/预览；迟到读取和授权不能恢复旧页面。选择token在授权返回前已登记，关闭时可以提前撤销。释放回调不返回自身Future，避免自等待；多个关闭请求共享正在执行的释放任务。

编辑前按同一个entry/version读取全部UTF-8分段，核对字节边界、总长度和元数据；不完整或变化的数据不会成为覆盖保存的正文。确认提交后才显示已保存，丢失回复只查询原request_id的回执，不自动重放。切换共享空间会清空成员标识并将权限模式恢复只读，避免把上一空间的授权上下文带到下一空间。

Core已固定升级为9c25820/schema28，人工确认继承既有模型来源，不能把已知文件依赖变成无来源声明。所有来源权限仍需真实当前授权，用户可为验证明确选择额外来源；它们不是自动授予模型的工具scope。

## 已验证

- 12项Rust Host测试、严格Clippy及Dart分析通过。
- 77项Flutter测试通过，其中8项记忆控制器/组件测试覆盖完整分段读取、迟到响应、关闭、丢失提交回复、明确确认按钮及成员编辑上下文清理。这里的UI命令输送器是明确替身。
- memory_management_test在真实macOS Flutter应用中调用实际FRB/SQLite：通过UI创建空间和确认保存15021字节中文内容；完整分段读取一致；关闭后旧选择拒绝；重开Host后需重新授权且记录仍在；只读写入拒绝。该测试没有模型推理、没有OS文件选择替身或外部账号。
- 原生渲染截图已检查，测试入口随后恢复为默认lib/main.dart，开发签名严格检查通过。当前开发helper包不含GGUF权重，最低macOS27.2；其他OS与生产签名/公证未验证。

## 仍未完成

手动管理不等于Agent记忆闭环。桌面任务尚需显式选择模型可见scope、只读权限收窄、proof-only来源、模型工具批准及恢复；LocalGateway仍需按AgentRequest验证记忆工具。原scope的撤权信号和排空必须覆盖收窄后的任务Grant，不能新建独立Grant使关闭失效。

还需完善重启后人类待确认草稿的元数据发现、显式草稿作废、禁用scope或来源不可用时的owner无正文清理，以及真实固定本地模型记忆闭环。这些缺口不以现有绿色测试替代，候选仍未合入主线。
