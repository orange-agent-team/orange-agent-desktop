# 桌面本地文档检索

在工作区面板授权本地目录后，展开“本地文档检索”，选择当前仍有效的工作区。每行输入一个需要开放的相对文件路径，点击“启用所选文档”。输入查询并选择匹配片段后，界面显示来源路径、文件摘要和重新从文件核对的原文。收费模型和网络连接不参与这个手动流程。

集合绑定到当前原生 Host、工作区的操作系统访问会话和本次文件选择。相同选择请求可以核对，修改原请求的文件清单会被拒绝。关闭了的集合编号不能重开。恢复或撤销工作区授权时需要重新建立集合。折叠面板、应用进入后台和工作区失权会清除显示的结果。展开期间，界面对当前展示的片段定期复核；文件改版或删除后会移除正文。

桥接使用固定的 `006ff38a3624cdd96e6d576afc3a4f5ca78b81ce` 共享运行时源包，随桌面工程保存并校验摘要。FRB 提供集合启用、查询、按引用读取和关闭四种操作。索引只驻留在进程内存中，客户端无法用模型参数提供其他磁盘根目录。

在已准备锁定 SDK 与匹配模型辅助程序的 macOS ARM64 开发环境，执行 `python3.12 scripts/check-selected-knowledge.py --native-app`。测试用临时目录模拟操作系统选择，随后通过真实 Flutter 窗口、Rust 原生库和 SQLite 工作区权限进行查询、文件删除、重新检索和撤权。传入 `--bridge-library` 可以对已解包的库验证同一套原生接口。手动文件选择器、其他操作系统、跨会话的知识索引和原生 Agent 对话中的自动工具选择另有各自的验收项。
