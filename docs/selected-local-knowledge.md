# 桌面本地文档检索

在工作区面板授权本地目录后，展开“本地文档检索”，选择工作区。每行填写一个文档相对路径，点击“启用所选文档”。输入查询、选择片段后，桌面会重新读取源文件，并显示路径、字节范围和 SHA-256 摘要。

默认集合使用内存索引。需要跨会话保留索引时，勾选“在本机保存索引”，填写集合名称和文件清单。应用重启后，先恢复工作区的操作系统访问，再通过“查看已保存的集合”选择名称，重新填写相同的文件清单。工作区权限、文件身份、内容版本及当前访问令牌均会核对。界面在折叠、应用进入后台及工作区失权时释放当前选择并清除正文。

“关闭文档集合”释放本次会话。“撤销已保存的集合”经确认后清除该集合的索引并使以前的引用失效。撤销工作区会在同一笔本地事务中登记该工作区所有待清理集合。应用启动时恢复未完成的清理，其他集合可以继续使用。若清理暂时失败，面板提供“重试清理”。同一份工作区授权内，已撤销的集合名称保留撤销记录；为新的选择使用新名称。

桌面桥接消费固定来源 `3a007ac99419c8825520bbc0f2ea7481b5a07f7c` 的共享运行时，编译输入和摘要保存在本仓库。管理集合的接口只向可信桌面宿主开放。默认内存模式、Journal 持久模式和真实模型调用分别验收。

在已准备锁定 SDK 与本机模型辅助程序的 macOS ARM64 开发环境，执行 `python3.12 scripts/check-selected-knowledge.py --native-app`。测试使用临时目录模拟操作系统目录选择，随后实际运行 Flutter 窗口、Rust 原生库及 SQLite。传入 `--bridge-library` 可以使用解包后的原生桥接库复测。其他操作系统的桌面访问选择器和原生 Agent 对话中的自动工具选择单列验收。
